opencode (local-only) fuer Windows x64
=====================================

Inhalt
  opencode.exe          opencode, gebaut aus github.com/Matthias-Gerhards/opencode_local
  rg.exe                ripgrep 15.1.0 (Dateisuche, wird von opencode benoetigt)
  opencode-offline.cmd  Startskript: setzt die Offline-Einstellungen und findet rg.exe
  opencode.jsonc        Konfigurationsvorlage

Einrichtung
  1. Diesen Ordner an einen festen Ort kopieren, z. B. C:\Tools\opencode-windows\
  2. opencode.jsonc nach %USERPROFILE%\.config\opencode\opencode.jsonc kopieren
     (Ordner ggf. anlegen) und im Abschnitt "firma" eintragen:
       - "baseURL": Adresse des Firmen-LLM-Servers, z. B. http://llm.intern:8000/v1
       - Modell-ID statt "modell-id" (so, wie GET <baseURL>/models sie liefert)
       - "context" / "output" passend zum Modell
     und ganz oben bei "model" dieselbe Modell-ID eintragen: "firma/<modell-id>"
  3. Verlangt der Server einen API-Key: in opencode-offline.cmd die Zeile
     "rem set FIRMA_API_KEY=..." aktivieren und den Key eintragen.
  4. Immer ueber opencode-offline.cmd starten, nicht direkt ueber opencode.exe.
     Im Projektordner:  C:\Tools\opencode-windows\opencode-offline.cmd

Pruefen
  opencode-offline.cmd models     -> muss "firma/<modell-id>" anzeigen

Probleme
  - Modell liest keine Dateien / ruft keine Tools auf:
    Server muss Tool-Calling unterstuetzen. Bei Denk-Modellen in opencode.jsonc
    beim Modell  "body": { "reasoning_effort": "none" }  setzen.
  - "Timed out waiting for response headers": in "settings" z. B.
    "headerTimeout": 900000 (Millisekunden) ergaenzen.
  - "ripgrep not found": rg.exe muss neben opencode.exe liegen.
  - "ECONNREFUSED" bzw. es wird ein Ollama-/LM-Studio-Modell benutzt:
    in opencode.jsonc "model": "firma/<modell-id>" setzen.
  - Websuche: ist fest im Programm gesperrt und laesst sich nicht einschalten.
  - Es wird trotzdem auf das Internet zugegriffen:
    opencode startet beim ersten Aufruf einen Hintergrund-Server, der nach dem
    Schliessen weiterlaeuft und bei jedem Start wiederverwendet wird. Wurde er
    einmal ohne opencode-offline.cmd gestartet, fehlen ihm die Offline-Einstellungen.
    Abhilfe:  opencode-offline.cmd service stop   (danach normal neu starten)

Update auf eine neue Version
  1. opencode schliessen und den Hintergrund-Server beenden:
       opencode-offline.cmd service stop
  2. opencode.exe durch die neue Datei ersetzen.
  3. Neue opencode.jsonc mit der eigenen vergleichen und neue Eintraege
     (z. B. "model") uebernehmen. Die eigene Datei nicht einfach ueberschreiben,
     sonst sind baseURL und Modell-ID wieder Platzhalter.
